粵鍵 YueKey 0.6.6 修正大階字母不能輸入速成的問題，並將 Ubuntu GNOME／Windows 語音提示改成游標下方的綠色小咪高峰。中文模式輸入 `HI` 和 `hi` 都會顯示「我」等候選字，按 `1` 選字；Caps Lock、按住 Shift 及混合大小階均可正常取碼。

YueKey 0.6.6 fixes uppercase Quick codes falling through as English text and places a green microphone capsule below the caret on Ubuntu GNOME and Windows. In Chinese mode, `HI` and `hi` show the same candidates, with `1` selecting 我. Caps Lock, held Shift and mixed case work consistently on Ubuntu, Kubuntu and Windows.

- **大小階 / Letter case:** letters follow the same spelling, selection and learning path. Uppercase Z-code punctuation works too, for example `ZB1 → ，`.
- **中英切換 / Language switching:** tapping the configured language key (Left Shift by default) still switches languages. English mode keeps normal capitalization; Ctrl/Alt/Super shortcuts and key releases are preserved.
- **關聯字 / Continuations:** uppercase input dismisses the continuation list and starts a new code without inserting the suggested word. Typing a third code letter retains the normal two-letter Quick behavior.
- **語音提示 / Microphone indicator:** a compact green capsule with an original white outline microphone is centred below the caret. It moves above at the bottom of the monitor and uses the text-start edge when only field bounds are available. Windows scales the drawing with display DPI and keeps keyboard focus in the input field. KDE retains its native Fcitx5 candidate-panel indicator.
- **更新狀態 / Update status:** Ubuntu Settings and `quick-hk dictation status` now detect when GNOME is still running an older extension and explain that the new appearance takes effect at the next login.
- **保留功能 / Existing features:** retains 0.6.5's 港/A Windows status icons, 75 traditional Z-code symbols, settings deployment fix and verified model-download retries.
- **Ubuntu / Kubuntu 26.04:** download `yuekey_0.6.6-1_amd64.deb` or `yuekey_0.6.6-1_arm64.deb`. Run `sudo apt install ./yuekey_0.6.6-1_$(dpkg --print-architecture).deb`, then `quick-hk setup`. Reload the input method to activate the typing fix without signing out. The all-in-one DEB includes CPU speech models; APT resolves system dependencies.
- **Windows:** choose the `windows-x64`, `windows-x86` or `windows-arm64` setup EXE. Setup preserves preferences and learning, deploys Cantonese Quick automatically, and installs the bundled Weasel prerequisite if missing. Portable ZIPs offer the same setup through **Overview → Set up typing**.
- **語音 / Voice:** CPU-only Cantonese recognition remains local. Windows downloads verified models on first enable. GNOME caches loaded extension JavaScript. The new green microphone appears at the next login after upgrading an already loaded extension; toggling the extension or restarting IBus cannot activate its new appearance. The typing fix can be activated by reloading Rime without signing out.
- **Limits:** no Linux i386/ARM32 packages or universal DEB for older distributions. Windows x86 is tested under WOW64, not a complete 32-bit OS. Hardware microphones and individual applications still need hands-on checks. Windows packages are not code-signed.
