粵鍵 YueKey 0.6.3 修正 Windows 語音模型下載的憑證鏈處理，針對舊版顯示 `CERTIFICATE_VERIFY_FAILED: unable to get local issuer certificate` 的情況。關閉粵鍵、安裝新版，再按「語音 → 啟用語音」。

YueKey 0.6.3 uses native Windows certificate-chain validation for voice model downloads, addressing issuer-chain errors in the previous downloader. Close YueKey, install this update, then choose **Voice → Enable voice** again.

- **HTTPS:** Windows now uses its managed trust store and native intermediate-certificate retrieval through truststore. Certificate and hostname verification remain enabled, alongside SHA-256 checks. Errors identify the file and source; existing models and partial downloads are preserved. A certificate that Windows does not trust still requires a system/network trust fix. [Troubleshooting](https://github.com/angusleung-armitage/YueKey/blob/v0.6.3/docs/WINDOWS.md#ssl-憑證錯誤--certificate-errors).
- **驗證 / Validation:** CI exercises real HTTPS redirects and resumed downloads, rejects an untrusted issuer and wrong hostname, and downloads/initializes the CPU models through the installed Windows app. The Windows x64, x86 and ARM64 jobs also retain installer, typing, settings and Cantonese sample checks.
- **輸入設定 / Typing:** Cantonese Quick remains the default and only selectable Rime scheme. Existing learning, shared bilingual settings, inline continuation previews and horizontal/vertical layouts are retained.

- **Windows:** choose the `windows-x64`, `windows-x86` or `windows-arm64` setup EXE. Approve the administrator prompt if Weasel is missing; compatible existing engines are reused. Setup preserves preferences and learning, then deploys Cantonese Quick automatically. Portable ZIPs include the same prerequisite through **Overview → Set up typing**.
- **新介面 / New interface:** Overview with readiness and a practice field; dedicated Typing, Voice and Advanced pages; branded icon; background setup and automatic deployment when saving settings.
- **廣東話語音 / Cantonese dictation:** CPU runtime included. First enable downloads about 302 MB of verified models. Double-tap Ctrl to start/stop; recognition runs locally without a GPU.
- **Ubuntu / Kubuntu 26.04:** choose `yuekey_0.6.3-1_amd64.deb` or `yuekey_0.6.3-1_arm64.deb`. Install with `sudo apt install ./yuekey_0.6.3-1_$(dpkg --print-architecture).deb`, then run `quick-hk setup` and `quick-hk configure`. The all-in-one DEB includes speech models; APT resolves system dependencies.
- **Limits:** no Linux i386/ARM32 packages or universal DEB for older distributions. Windows x86 is tested under WOW64, not a complete 32-bit OS. Hardware microphones and individual applications still need hands-on checks. Windows packages are not code-signed.
